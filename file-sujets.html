File de sujets

Tous les sujets en attente et déjà publiés, avec leur dossier : question, contexte, rationnel, mots-clés pour chercher les articles. Lecture seule — la source est data/sujets.json.

Compléter les dossiers incomplets : lancer le workflow « Enrichir les dossiers de sujets » (GitHub Actions, bouton « Run workflow »). Il remplit ce qui manque, par lots, sans jamais écraser un champ déjà écrit.

Valider ou prioriser un sujet : les boutons de chaque fiche (« ✓ Valider ce sujet » pour un sujet 🔍, « 🔥 Passer en priorité absolue », « Retirer de la priorité ») lancent le workflow « Valider ou prioriser des sujets ».
