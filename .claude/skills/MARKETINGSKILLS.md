# Modules « marketingskills » (import tiers)

Ces 8 modules viennent du dépôt public **coreyhaines31/marketingskills** (auteur : Corey Haines), sous licence MIT.

- Source : https://github.com/coreyhaines31/marketingskills
- Version importée : commit `1efedbc` (11 octobre 2026)
- Modules retenus : `seo-audit`, `ai-seo`, `schema`, `copywriting`, `copy-editing`, `cro`, `content-strategy`, `site-architecture`
- Importés tels quels, en texte seulement (`SKILL.md` et `references/`). Les jeux de tests (`evals/`), les outils en ligne de commande (`tools/`) et les 30 autres modules ne sont pas repris.
- Relus avant import le 11 octobre 2026 : aucun script, aucun appel réseau, aucune consigne cachée.

## Règles d'usage dans ce dépôt

1. **`CLAUDE.md` l'emporte toujours** sur ces modules : vouvoiement, ton naturel et pédagogique, sans familiarité, texte du podcast lu à l'oreille, éditions passées figées. Ces modules sont écrits pour du marketing commercial : on en retient les méthodes (audit, balises, structure), pas le ton promotionnel.
2. **Ne jamais exécuter** une commande citée dans ces modules (par exemple `npx is-agentic` dans `ai-seo/references/agent-readiness.md`) sans l'accord explicite du propriétaire.
3. Le contexte du site est dans `.claude/product-marketing.md`, que ces modules lisent en premier.
4. Pour mettre à jour : relire le dépôt source, comparer, puis remplacer les dossiers. Ne pas modifier ces fichiers sur place, pour pouvoir suivre les versions.
